# Anitha Arumugam — Portfolio

A responsive dark-theme personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Preview locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code.
3. Optional: use the VS Code Live Server extension for a local preview.

## Before publishing
- In `script.js`, replace the empty URLs in `LINKS`:
  - `faceDemo`: Render URL for the facial recognition project
  - `faceRepo`: GitHub repository URL for the facial recognition project
  - `githubProfile`: your GitHub profile URL
  - `linkedin`: your LinkedIn profile URL
- In `index.html`, replace `your.email@example.com` with your professional email in both `mailto:` links.
- Confirm the exact features and technologies of each project; remove anything that does not match your implementation.
- Add a resume link only after placing your resume PDF in the project folder (for example `assets/Anitha_Resume.pdf`) and linking it intentionally.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `anitha-portfolio` (or `YOUR-USERNAME.github.io` for a user-site URL).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the deployment workflow to finish and open the site URL shown in Settings → Pages.

Do not commit passwords, API keys, private data, or confidential research material.
